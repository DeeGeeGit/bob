# Brainstorming — Single Agent

Do the design work yourself. Never call `Task`, `Agent`, `subagent`, create
teammates, or use agent teams. Inspect the project and applicable specs first.

Clarify intent one question at a time when needed, identify constraints and
acceptance criteria, compare two or three approaches, and recommend the smallest
reversible design. Record the validated design in `.bob/state/design.md` before
implementation. Respect existing specs and explicitly flag any contract change.
